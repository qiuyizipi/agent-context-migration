# Agent 上下文迁移

这是一个把 WorkBuddy 项目记忆、历史对话和项目规则迁移到 Codex 的操作流程。

## 怎么用

1. 先阅读[操作流程](操作流程.md)。
2. 用 `scripts/inspect-workbuddy.ps1` 只读扫描来源文件。
3. 参考 `examples/manifest.example.json` 建立迁移清单。
4. 将每个原始顶层对话分别保存，不要把多个对话合并成一个总结。
5. 迁移后检查数量、标题、路径和 SHA-256。

## 重要说明

迁移的是项目上下文和原始历史档案，通常不能把旧 Agent 的聊天界面逐轮恢复到 Codex 中。

不要上传真实对话、数据库、密钥、私有代码或本机路径。
